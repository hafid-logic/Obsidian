# OpenClaw

> [!abstract] ما هو؟
> وكيل ذكاء اصطناعي مفتوح المصدر self-hosted — ==أسرع مشروع نمواً في تاريخ GitHub (250 ألف نجمة/60 يوماً)==؛ «يفعل» الأشياء لا «يجيب» عنها: يعمل 24/7 في الخلفية، يتكامل مع WhatsApp/Telegram/Discord، وله متجر مهارات (Claw Hub).

## الدور المسجل في المحادثة
- مرشح أول لتسيير صفحة بيع التمور ([[2026-11-12 OpenClaw Agent Stack]]) — مع استكشاف تشغيله على Oracle Free Tier ببطاقة Payoneer أو في Codespaces.
- ==تحذيرات أمنية موثقة: مهارات خبيثة في المتجر، صلاحيات عميقة على النظام والملفات== — لا يعمل إلا داخل حاوية معزولة؛ تاريخ التسمية Clawdbot ← Moltbot ← OpenClaw تحت ضغط Anthropic القانوني.

## الخلاصة العملية
> [!callout] القرار
> ==لم يُعتمد== — مكان OpenHands (OpenDevin) في مكدس المنصة؛ يبقى موضوع رصد أمني وبديلاً محتملة.
