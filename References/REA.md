# REA

## الملخص (Summary)
بيئة الهندسة العكسية التي اعتمدها hafid في [[Sandoq]] (الإصدار 6.7.0): MCP server تتيح للوكلاء والنماذج فحص الثنائيات وتحليلها. المستودع المرجعي [morluto/rea](https://github.com/morluto/rea) مفتوح المصدر بترخيص MIT. نقشت علاقتها بمشاريع أخرى في [[2026-11-10 REA Myrmico Discussion]].

> [!danger] تحذير أمني موثق
> وُجدت نسخة مزيفة باسم **rea-tools** وُزعت محمّلة بحصان طروادة — والنسخة المزيفة أيضاً تعيد شيفرة زائفة فقط لا المصدر الأصلي. التحميل من المستودع الرسمي حصراً.

## أبرز النقاط (Highlights)
- استُخدمت في تحليل WinRAR 7.12 (استخراج 2935 سلسلة و107 مفتاح تبديل) وفي جلسات OpenCode المرافقة.
- إعداداتها ومفتاحها ضاعا مع تدوير الصندوق مرتين — إعادة التثبيت `npm install -g rea` وإعادة بناء MCP config.

## التقييم (Rating — سلّم kepano من 7)
**5/7** — أداة عملية فعلية في سير العمل، لكن الاعتماد على حساباتها المجانية (حصص) هشّ.
