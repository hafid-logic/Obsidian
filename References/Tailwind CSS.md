# Tailwind CSS

## الملخص (Summary)
إطار CSS بالأدوات المساعدة (utility-first) تعتمده صفحة هبوط دقلة نور عبر CDN: بناء واجهات متجاوبة بسرعة (شبكة عمودين على الموبايل وأربعة على الحاسوب) مع خط Cairo واتجاه RTL.

## أبرز النقاط (Highlights)
- CDN يكفي للصفحات الخفيفة والتجريبية، لكنه غير موصى به للإنتاج الكبير (حجم أكبر وأنماط تُحسب وقت التشغيل) — الأفضل تجميع نسخة نهائية مع تنقية (purge).
- الأنماط المخصصة في صفحة الهبوط (معرض الصور وLightbox) كُتبت CSS خاماً داخل وسم `style` بجانب أدوات Tailwind — نمط عملي لصفحات الملف الواحد.

## التقييم (Rating)
6/7 — الخيار الأنسب لصفحة هبوط سريعة الإنجاز بمظهر عصري متجاوب.
