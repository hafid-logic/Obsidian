# OpenHands (OpenDevin)

> [!abstract] ما هو؟
> وكيل تطوير برمجيات مفتوح المصدر (الاسم السابق OpenDevin) — ينفذ مهام هندسية كاملة داخل بيئة معزولة: قراءة مستودع، كتابة كود، تشغيل اختبارات.

## الدور المسجل في المحادثة
- ==الوكيل المعتمد لمشروع منصة التمور== بعد مقارنة طويلة داخل [[2026-11-12 OpenClaw Agent Stack]]: خيار استراتيجي طويل الأمد «بشروط» — تشغيله في GitHub Codespaces لتجاوز ضعف الجهاز.
- البنية المعتمدة: ==مستودع خاص بكود المنصة منفصل عن كود الوكيل== — لا يوضع OpenHands في المستودع الخاص.

## الخلاصة العملية
> [!callout] القرار
> مكدس الوكيل: OpenHands في Codespaces + مستودع منصة مستقل — يسبق أي عمل تنفيذي على صفحة التمور المؤتمتة.
