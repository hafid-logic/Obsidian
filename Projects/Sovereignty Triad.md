# Sovereignty Triad

> [!abstract] الهدف (Goal)
> بروتوكول لوجستيات محلي لإدارة موارد فيزيائية (طاقة/غذاء/معادن) في مناطق معزولة — Zero-Trust وغير خطي، بشبكة LoRaWAN مشفرة بلا بوابة مركزية.

## النطاق (Scope)
- يشمل: هيكل JSON لتتبع الموارد (طاقة 1,500 kWh، غذاء 350 kg، معادن 800 kg) بوصف طزاجة وتحويلات، كود Python بمحفزات تدهور آلية (طزاجة < 0.40 أو توافر < 0.5)، ومعمارية LoRaWAN نقطة-إلى-نقطة (ESP32/STM32 + SX1276/8، 868/915 MHz، SF9-SF12، AES-256-CTR + HMAC-SHA256، مدى 15-50 كم بخط نظر).
- لا يشمل: تأطيراً جيوسياسياً أو تحليل «هجمات أنظمة مركزية» — رُفض في المحادثة التأسيسية واعتُمد الإطار التقني الصرف.
