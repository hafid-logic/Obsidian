# DePIN Algeria

> [!abstract] الهدف (Goal)
> شبكة حوسبة لامركزية DePIN جزائرية تستثمر الطاقة الرخيصة المحلية لتقديم حوسبة بـ25% من الكلفة الغربية — تبدأ بمهام معالجة خفيفة على أجهزة موزعة وتتدرج نحو شبكة حاسوب فائق موزعة.

## النطاق (Scope)
- يشمل: منسق مركزي Python + عقد (node_client.py) + SDK للعملاء، تطبيق React Native، PostgreSQL؛ اقتصاديات 83% هامش ربح (60 هاتفاً تخدم عميلاً واحداً: ربح $5,000 شهرياً بكلفة ~$1,000) وعائد $15-45 شهرياً لكل مالك جهاز.
- لا يشمل: المنافسة المباشرة في الأحمال الثقيلة (GPU) نظراً لقيود شبكة 4G الجزائرية — الحل: مهام بيانات خفيفة.
